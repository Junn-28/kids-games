# こどもゲーム / kids-games

こども向けのブラウザゲーム集です。スマホ・タブレット・PC のブラウザだけで遊べます。

**あそぶ → https://junn-28.github.io/kids-games/**

- 広告なし・登録なし・課金なし
- 外部への通信を一切しません（CSP で禁止しています）
- セーブデータは遊んでいる端末の `localStorage` の中だけ。サーバーには送りません

## リポジトリ構成

1つのゲーム = 1つのフォルダ。ゲームを増やしても、既存のゲームには一切触りません。

```
kids-games/
├─ index.html              ポータル（ゲームをえらぶ画面）
├─ vite.config.js          games/ を走査して自動でビルド対象にする
├─ src/
│  ├─ portal.jsx           ポータルの中身
│  ├─ games.js             ゲーム登録簿（ゲームを足すときはここに1行）
│  └─ shared/              全ゲーム共通の部品
│     ├─ storage.js        セーブの読み書き＋値の検証
│     ├─ useBlip.js        効果音（音源ファイルなし＝通信なし）
│     ├─ theme.js          フォント・配色
│     └─ base.css          下地スタイル
├─ games/
│  └─ sakana/              ← ゲーム1つぶんが、まるごとこの中で完結する
│     ├─ index.html        エントリ（CSP はここに書く）
│     ├─ main.jsx          マウント
│     └─ SakanaGame.jsx    ゲーム本体
└─ .github/workflows/deploy.yml   main への push で GitHub Pages へ自動デプロイ
```

この形にした理由:

- **ゲームどうしが独立している。** 新しいゲームを足しても、他のゲームのコードもビルド設定も変わりません。壊れるとしたらそのゲームの中だけです。
- **ビルド設定を触らなくていい。** `vite.config.js` が `games/*/index.html` を自動で拾います。
- **共通部分だけ `src/shared/` に集約。** セーブ処理や効果音を各ゲームで書き直さずに済みます。
- **1ゲーム = 1ページ。** ゲームを開いたときに、そのゲームのコードだけを読み込みます。数が増えても重くなりません。
- **セーブキーはゲームごとに分離。** `sakanaya:save:v1` のように接頭辞を付けるので、ゲーム間でデータが混ざりません。

新しいゲームの足しかたは [docs/adding-a-game.md](docs/adding-a-game.md) を参照。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # dist/ に出力
npm run preview  # ビルド結果を確認
```

## デプロイ

`main` ブランチに push すると GitHub Actions がビルドして GitHub Pages に公開します。
手動デプロイは不要です。

## 安全性について

こどもが使うものなので、次を守っています。

- **外部通信なし。** CSP を `default-src 'none'` から組み立て、許可しているのは同一オリジンのファイルだけです。広告 SDK・アクセス解析・フォント CDN・外部画像を一切読み込みません。絵はすべて絵文字なので画像ファイルもありません。
- **個人情報を集めない。** 入力欄がなく、Cookie も使わず、名前もメールアドレスも聞きません。保存するのは所持金や魚の種類といったゲームの進行状況だけで、それも端末の中だけです。
- **外部リンクなし。** うっかり別サイトに飛ぶ経路がありません（CSP の `form-action 'none'` でフォーム送信も塞いでいます）。
- **セーブデータを信用しない。** `localStorage` は本人が書き換えられるので、読み込み時に全項目を型・範囲チェックします。壊れていたら「セーブなし」として最初から始めます。
- **`dangerouslySetInnerHTML` / `eval` を使わない。** 文字列はすべて React 経由で描画するので、XSS の入り口がありません。
- **依存を最小に。** 実行時の依存は React と React DOM だけです。
